# 04: Human-in-the-Loop (HITL) 就地核对、编辑修正与数据闭环 (HITL In-place Verification & Editing)

**What to build:** 在聊天气泡表格卡片上赋予用户直接核对、就地编辑与终态确认的人机协同能力。卡片自动显示绿色算力校验通过徽标（或橙色偏差告警）；用户可一键切换为行内编辑模式，修改表格中任一数字（如箱数、台数）或文本（如签名），系统实时联动重算验证结果；点击“确认保存”后卡片更新为终态核实状态，并提供“一键复制 JSON”与后续追问上下文联动。

**Blocked by:** 03: Shadcn AI Elements 聊天流与内嵌横向表格呈现

**Status:** resolved

## Acceptance Criteria

- [x] 表格卡片上显式渲染算力一致性状态徽标（$\sum \text{单箱台数} \times \text{绑扎箱数} = \text{车装总台数}$）
- [x] 卡片右上角提供【编辑修正】操作按钮，点击后表格所有数据项转为就地 Input 控件
- [x] 用户在编辑输入时，底部的计算值实时动态联动重算，直观展示差异
- [x] 点击【确认保存】后，修改就地固化，并在卡片标明“已由人工核实验收”
- [x] 支持点击【复制标准 JSON】或【导出数据】，获得完全结构化的清洗后结果
- [x] 交互组件自动化行为测试通过（Seam 2 验证）
