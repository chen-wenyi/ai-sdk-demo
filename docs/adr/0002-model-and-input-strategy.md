# 视觉模型适配与纯用户图片上传流转策略 (Model & Pure Upload Strategy)

## Context
用户截屏展示了其模型平台列表，包含 `qwen3-vl-plus`（Qwen3 视觉理解模型）、`qwen-vl-ocr`（专项 OCR 模型）等，不存在 `vl max`；同时用户明确不需要预置测试样例按钮，要求纯净的原生图片输入。

## Decision
1. **模型选型与配置**：默认选用多模态理解与 JSON 遵循能力强劲的 `qwen3-vl-plus`，同时界面提供下拉切换至 `qwen-vl-ocr` 或自定义模型名称；Base URL 支持自定义配置（兼容百炼与硅基流动等 OpenAI 兼容格式）。
2. **纯净图片输入**：去除任何预置样例注入，聊天框提供标准的图片拖拽、粘贴或点击文件上传，图片以 Data URL（Base64）随聊天请求发往后端进行视觉解析。

## Consequences
- 完全贴合用户实际持有的模型列表，零配置门槛即可启动。
- 界面更简洁、无冗余 demo 按钮，符合正式生产级工具的体验。
