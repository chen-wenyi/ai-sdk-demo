# 聊天框内交互式核验与人工修正机制 (In-Chat Human-in-the-Loop Table)

## Context
码头纸质统计表存在手写体、复杂横向多级表头和印刷模糊等情况。纯大模型提取可能会出现微小偏差或漏项，需要高可信度保障。同时用户要求表格紧凑地展示在聊天气泡内。

## Decision
我们决定采用 Vercel AI SDK 的结构化输出（JSON Schema）将“E伟捷”的识别结果直接作为结构化部件嵌入到聊天气泡中，并配备 **就地核验与编辑模式（Human-in-the-Loop）**：
1. 自动对数据做算术一致性校验（$\sum \text{单箱台数} \times \text{绑扎箱数} = \text{绑扎车装台数}$）。
2. 提供可一键切换的行内编辑形态，用户无需离开聊天流即可微调数字或签名，并可一键“确认入账”。

## Consequences
- 避免传统 AI 问答只输出静态 Markdown 文本无法二次交互的问题。
- 保证用户在聊天界面内即可完成“AI识别 → 自动校验 → 人工修正 → 终态确认”完整闭环。
